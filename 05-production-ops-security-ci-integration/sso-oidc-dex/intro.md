### Lab Module: sso-oidc-dex SSO OIDC with Dex
🎯 Module Objectives

1. Understand Dex role as OIDC identity broker for Argo-CD
2. Configure Dex OIDC connector (e.g. GitHub / Keycloak)
3. Map OIDC groups to Argo-CD RBAC groups
4. Test SSO login flow

📖 Official reference: [https://argo-cd.readthedocs.io/en/stable/operator-manual/user-management/](https://argo-cd.readthedocs.io/en/stable/operator-manual/user-management/)
Prerequisite: rbac-permission lab completed.
Complete step1 ~ step3 sequentially.
