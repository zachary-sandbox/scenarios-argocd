### Lab Module: rbac-permission Argo‑CD RBAC Permission
🎯 Module Objectives
1. Understand Argo‑CD RBAC model and policy syntax
2. Configure role and policy in argocd‑cm configmap
3. Create read‑only user and application‑limited permission
4. Validate permission effect via UI / CLI

📖 Official reference: [https://argo-cd.readthedocs.io/en/stable/operator-manual/rbac/](https://argo-cd.readthedocs.io/en/stable/operator-manual/rbac/)
Prerequisite: Phase1‑4 completed, understand Argo‑CD project concept.
Complete step1 ~ step3 sequentially.
