🎯 Module Objectives

1. Troubleshoot repo‑server git repository access failure
2. Debug OutOfSync difference using UI diff and argocd app diff cli
3. Collect component logs for debugging
4. Common error classification and investigation thinking

Complete step1 ~ step3 sequentially.
