### Lab Module: notifications Argo-CD Notifications
🎯 Module Objectives

1. Understand argo-notifications architecture
2. Install Argo-CD notifications controller
3. Configure trigger, template and notification service destination (webhook)
4. Test notification when application sync status changed

📖 Official reference: [https://argo-cd.readthedocs.io/en/stable/operator-manual/notifications/](https://argo-cd.readthedocs.io/en/stable/operator-manual/notifications/)
Prerequisite: basic Argo-CD application operation knowledge.
Complete step1 ~ step3 sequentially.
