### Lab Module: prometheus‑metrics Argo‑CD Prometheus Metrics
🎯 Module Objectives

1. Learn Argo‑CD built‑in prometheus metrics endpoints
2. Enable metrics in argocd‑cm configmap
3. Access /metrics endpoint, view sync status, out‑of‑sync gauge metrics
4. Understand key production metrics

📖 Official reference: [https://argo-cd.readthedocs.io/en/stable/operator-manual/metrics/](https://argo-cd.readthedocs.io/en/stable/operator-manual/metrics/)
Prerequisite: basic kubernetes port‑forward operation.
Complete step1 ~ step3 sequentially.
