### Lab Module: jenkins-argocd-gitops Jenkins + Argo-CD GitOps End-to-End Pipeline
🎯 Module Objectives
1. Understand GitOps separation of duties: CI(Jenkins) vs CD(Argo-CD)
2. Jenkins responsibility: build image, push image, update git manifest image tag
3. Argo-CD responsibility: detect git change, sync manifests to Kubernetes
4. Build full CI-CD GitOps workflow

📖 Official reference: [https://argo-cd.readthedocs.io/en/stable/user-guide/ci](https://argo-cd.readthedocs.io/en/stable/user-guide/ci)-cd-integration/
Prerequisite: Jenkins basic knowledge, Argo-CD Application.
Complete step1 ~ step3 sequentially.
