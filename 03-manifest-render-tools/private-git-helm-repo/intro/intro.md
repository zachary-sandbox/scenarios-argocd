### Lab Module: private-git-helm-repo Private Git and Helm Repositories
🎯 Module Objectives
1. Configure Argo CD repository credentials for private Git repositories
2. Configure Argo CD to pull charts from private Helm repositories
3. Verify that private sources can be used in Application manifests

📖 Official reference: https://argo-cd.readthedocs.io/en/stable/user-guide/private-repositories/
Prerequisite: completed previous Phase 3 modules.
Complete step1 ~ step3 sequentially.
