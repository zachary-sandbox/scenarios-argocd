### Lab Module: plain-yaml Plain YAML Manifest Source
🎯 Module Objectives
1. Use a plain YAML directory as an Argo CD application source
2. Understand how Argo CD discovers and applies raw Kubernetes manifests
3. Practice adding, modifying, and deleting YAML files in Git and observing reconciliation behavior

📖 Official reference: https://argo-cd.readthedocs.io/en/stable/user-guide/application_sources/
Prerequisite: Phase 1 and Phase 2 completed, Argo CD running, basic Application CR knowledge.
Complete step1 ~ step3 sequentially.
