### Lab Module: argocd-cli-ui-login UI and CLI authentication
🎯 Module Objectives
1. Install argocd CLI binary tool
2. Retrieve admin initial password from Kubernetes secret
3. Use kubectl port-forward to access Argo-CD Web UI and login via browser
4. Complete argocd cli login and validate connectivity with argocd version

📖 Reference: https://argo-cd.readthedocs.io/en/stable/getting-started/#access-the-argo-cd-ui
Prerequisite: install-argocd lab completed, all Argo-CD pods Running.
