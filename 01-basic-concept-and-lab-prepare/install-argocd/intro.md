### Lab Module: install-argocd Deploy Argo-CD official manifests
🎯 Module Objectives
1. Create dedicated argocd Kubernetes namespace
2. Apply official Argo-CD install manifest with server-side apply for large CRDs
3. Wait for CRD resources establishment
4. Verify all Argo-CD pods transition to Running state

📖 Official Quick-Start: https://argo-cd.readthedocs.io/en/stable/getting-started/
Prerequisite: local-k8s-lab lab finished, working Kubernetes cluster.
