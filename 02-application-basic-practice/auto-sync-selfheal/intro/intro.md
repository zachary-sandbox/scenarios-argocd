### Lab Module: auto-sync-selfheal Automated sync, self-heal and prune
🎯 Module Objectives
1. Understand syncPolicy.automated block parameters
2. Enable selfHeal: manual cluster modifications get automatically reverted
3. Enable prune: resources removed from git get deleted from cluster
4. Observe behaviour when git manifest receives new commit

📖 Official reference: https://argo-cd.readthedocs.io/en/stable/user-guide/auto_sync/
Prerequisite: finished sync-operation lab.
Complete step1 ~ step3.
