### Lab Module: create‑app‑via‑cli Create Application via argocd CLI
🎯 Module Objectives
1. Use `argocd app create` command to imperatively create application
2. Use `argocd app get` to inspect application status from cli
3. Practice declarative way: kubectl apply Application yaml manifest

📖 Official reference: https://argo-cd.readthedocs.io/en/stable/user-guide/commands/argocd_app_create/
Prerequisite: argocd cli already logged‑in from phase‑1 lab.
Complete step1 ~ step3.
