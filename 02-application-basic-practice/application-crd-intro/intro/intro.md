### Lab Module: application-crd-intro Understand Application CRD
🎯 Module Objectives
1. Understand Application CRD core spec fields: source, destination, syncPolicy
2. Interpret status sub-fields: syncStatus, healthStatus

Prerequisite: Phase-1 lab finished, Argo-CD is up and running.
Complete step1 ~ step3 sequentially.
