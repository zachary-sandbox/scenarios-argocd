### Lab Module: helm-chart-basic Helm Chart Basic
🎯 Module Objectives
1. Understand how Argo CD renders Helm charts
2. Deploy an application from a Helm chart stored in Git
3. Understand why you cannot use `helm rollback` command to rollback ArgoCD Helm-based application
4. Understand why Git repo source is more recommended for production

📖 Official reference: https://argo-cd.readthedocs.io/en/stable/user-guide/helm/
Prerequisite: Argo CD running, basic Helm concepts helpful.
Complete step1 ~ step4 sequentially.
