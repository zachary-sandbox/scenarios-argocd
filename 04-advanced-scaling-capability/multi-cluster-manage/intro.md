### Lab Module: multi-cluster-manage Multi-Cluster Management
🎯 Module Objectives
1. Understand how Argo CD manages multiple Kubernetes clusters
2. Register an external cluster into Argo CD
3. Deploy an application to a remote target cluster
4. Understand cluster credential security

📖 Official reference: https://argo-cd.readthedocs.io/en/stable/operator-manual/declarative-setup/#clusters
Prerequisite: access to a second Kubernetes cluster or additional kubeconfig context.
Complete step1 ~ step3 sequentially.
