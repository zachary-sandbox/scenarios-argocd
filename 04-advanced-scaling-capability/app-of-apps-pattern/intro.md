### Lab Module: app-of-apps-pattern App-of-Apps Pattern
🎯 Module Objectives
1. Understand the App-of-Apps pattern for managing multiple applications
2. Create a parent Application that manages child Application CRs
3. Add new child applications in Git and observe automatic creation
4. Understand parent-child reconciliation behavior

📖 Official reference: https://argo-cd.readthedocs.io/en/stable/operator-manual/cluster-bootstrapping/
Prerequisite: Phase 1-3 completed, Argo CD Application CR understanding.
Complete step1 ~ step3 sequentially.
