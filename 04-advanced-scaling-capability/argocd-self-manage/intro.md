### Lab Module: argocd-self-manage Argo CD Self Management
🎯 Module Objectives
1. Understand what it means for Argo CD to manage itself
2. Store Argo CD installation manifests in Git
3. Create an Application that manages Argo CD itself
4. Understand self-management risks and safeguards

📖 Official reference: https://argo-cd.readthedocs.io/en/stable/operator-manual/declarative-setup/
Prerequisite: completed previous Phase 4 modules.
Complete step1 ~ step3 sequentially.
