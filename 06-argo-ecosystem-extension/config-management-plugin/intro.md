### Lab Module: config-management-plugin Custom Config Management Plugin
🎯 Module Objectives
1. Understand Argo-CD Config-Management-Plugin mechanism
2. Register custom plugin to repo-server
3. Use custom plugin to render manifests for Application source
4. Test custom template rendering result

📖 Official reference: [https://argo-cd.readthedocs.io/en/stable/operator-manual/config-management-plugins/](https://argo-cd.readthedocs.io/en/stable/operator-manual/config-management-plugins/)
Prerequisite: Understand repo-server rendering workflow.
Complete step1 ~ step3 sequentially.
